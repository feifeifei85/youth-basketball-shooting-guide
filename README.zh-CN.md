# 青少年投篮训练手册

[English](README.md)

我是一名喜欢篮球的中学生。

投篮看起来很简单，真正练起来却有很多细节。教练教了我不少有用的方法。平时训练时，我也常常会想：为什么这一球投得很顺，下一球却偏了？怎样才能做得更好？

我把学到的东西和自己的想法记下来，做成了这份小手册，也想分享给其他喜欢篮球的同学。我还在练习，也在尝试不同的训练方法，所以这不是专业教材，也不一定有标准答案。它更像是我的篮球学习笔记。

我也会用 AI 等工具帮助整理笔记、比较不同的想法，让内容更容易看懂。不过，篮球还是要回到球场上，一球一球地练。

打开 [`index.html`](index.html) 就能阅读手册。
